# 아기 기록 (baby-log)

수유·기저귀·수면을 버튼 한 번으로 기록하는 육아 기록 앱입니다. Expo(React Native)로 만들었어요.

## 지금 되는 것 (1주차)
- 수유: 모유 왼쪽 / 오른쪽, 분유(ml 선택, 지난번 양 기억)
- 기저귀: 소변 / 대변
- 수면: 잠들었어요 → 깼어요 (자는 시간 자동 계산)
- 맨 위에 "마지막 수유 / 마지막 기저귀가 몇 분 전인지" 표시
- 날짜별 기록 목록, 기록 직후 "되돌리기", 길게 눌러 지우기
- 기록은 휴대폰 안에 저장돼요 (앱을 껐다 켜도 남아 있어요)

## 2단계
- **수유 알림**: 수유 간격(1시간 30분~4시간, 15분 단위 조절)을 정하면 마지막 수유 후 그 시간이 됐을 때 알림. 그때도 기록이 없으면 30분 뒤 한 번 더.
- 밤 10시~아침 7시에는 소리·진동 없이 알림만 (켜고 끌 수 있어요)
- 기록 화면 맨 위에 "다음 수유까지 남은 시간"
- **통계**: 오늘 요약(수유·분유량·평균 수유 간격·기저귀·수면, 하루 흐름 그림), 최근 7일·30일 하루 평균과 날짜별 그래프

## 휴대폰에서 보는 방법 (Windows 컴퓨터 + 안드로이드 휴대폰)
1. 휴대폰에 **Expo Go** 앱을 설치하고, 가지고 있는 Expo 계정으로 로그인합니다.
2. 컴퓨터에 **Node.js**(LTS 버전)를 설치합니다: https://nodejs.org
3. 이 저장소를 내려받습니다. GitHub 페이지에서 초록색 **Code** 버튼 → **Download ZIP** → 압축 풀기.
4. 압축 푼 폴더를 열고, 주소창에 `cmd` 라고 쓰고 Enter를 누르면 검은 창이 열립니다.
5. 검은 창에 아래 두 줄을 차례로 입력합니다.
   ```
   npm install
   npx expo start
   ```
6. 화면에 QR 코드가 나오면, 휴대폰의 Expo Go에서 **Scan QR code**로 찍습니다.
   (컴퓨터와 휴대폰이 **같은 와이파이**에 연결돼 있어야 해요.)

## 3단계: 가족 공유
- '가족' 메뉴에서 아기를 등록하면 6자리 초대 코드가 생겨요. 가족이 그 코드를 입력하면 같은 아기 기록을 실시간으로 함께 보고 써요.
- 회원가입 없이 호칭(엄마, 아빠 등)만 고르면 돼요. 기록 옆에 누가 기록했는지 보여요.
- 처음 시작할 때 그동안 휴대폰에 쌓인 기록도 함께 옮겨요.
- 클라우드는 Supabase를 써요. `supabase/schema.sql`을 Supabase SQL Editor에서 한 번 실행하고, 익명 로그인을 켜고, `src/config.ts`에 Project URL과 publishable key를 넣으면 켜져요. 비워 두면 예전처럼 휴대폰에만 저장해요.
